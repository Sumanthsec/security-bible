# S3 (Simple Storage Service)
Tags:

## Core

**S3** = AWS **object storage** (one of the first AWS services). Stores **objects** (data + metadata + a unique ID) in **buckets**; buckets support file paths like a directory. Built for unstructured data (images, video, backups) — web-accessible, durable, highly available.

**#1 source of AWS data leaks** — most big AWS breaches are a misconfigured S3 bucket. Keeping one bucket secure is easy; keeping *all* of them secure at scale (many teams, some legitimately public) is the hard part.

## Attack Surface

- Buckets/objects are **private by default**, but easy to make public **accidentally** — via a bucket policy *or* several other mechanisms. That variety of ways to expose is the core problem.
- Internet/URL access **never touches IAM** (no API call, no identity) → it's governed by [[resource-based-policies|bucket policies]], not identity-based policies or SCPs.

## Audit

- **Block Public Access (BPA)** — on by default. At the account level it prevents *any* bucket from being made public (private sharing still works), across all S3 policy types. Leave it on until you truly need otherwise.
